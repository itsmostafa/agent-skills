# bruh

**Plain-language restatements on demand.** When the agent's last message is full of jargon, type `/bruh` and it says the same thing again, simpler and shorter, like one human talking to another.

## How to use it

Run it right after a reply you couldn't follow:

```text
/bruh
```

The skill only runs when you invoke it. The agent never loads it on its own.
